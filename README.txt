СОДЕРЖИМОЕ
index.html — готовая интерактивная страница.
portrait.jpg — новый портрет на сайте.
avatar.jpg — квадратная фотография для миниатюр и VCF.
isaev-vyacheslav.vcf — контакт для iPhone/Android: «Исаев Вячеслав», без отчества, фото встроено.
telegram-qr.png — отдельный QR Telegram (на странице НЕ показывается).

КАК ОБНОВИТЬ СВОЮ ВИЗИТКУ НА GITHUB PAGES
1. Сохраните и распакуйте архив на компьютер.
2. Откройте именно СВОЙ существующий репозиторий GitHub Pages с личной визиткой (НЕ Isae-andrey — это визитка Андрея Константиновича).
3. В корневом каталоге замените index.html на новый. Загрузите portrait.jpg, avatar.jpg и isaev-vyacheslav.vcf. Можно также загрузить telegram-qr.png.
4. Если в репозитории уже были файлы с такими именами, GitHub покажет замену; подтвердите commit.
5. Проверьте, что index.html и isaev-vyacheslav.vcf лежат в корне репозитория, а не во вложенной папке.
6. После обновления GitHub Pages откройте СВОЮ старую ссылку и проверьте звонок, почту, Telegram и сохранение контакта на iPhone.
7. Старый QR-код продолжит работать, если адрес сайта не менялся.

ВАЖНО: репозиторий GitHub Pages с открытым доступом делает портрет, телефон и почту публично доступными.
Формат VCF 3.0 / UTF-8; фото JPEG встроено в файл. На iPhone в Safari может понадобиться открыть скачанный .vcf через «Файлы» и нажать «Создать новый контакт».
